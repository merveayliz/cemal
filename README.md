## 📖 Proje Hakkında / About
**TR:** Cemal, kullanıcı odaklı tasarımı ve akıcı arayüzü ile dikkat çeken özel bir web projesidir. Estetik ve işlevselliği bir arada sunmayı hedefler.

**EN:** Cemal is a special web project that stands out with its user-centric design and smooth interface. It aims to offer aesthetics and functionality together.

---

## ✨ Özellikler / Key Features
- 💻 **Modern Arayüz / Modern UI:** Temiz ve düzenli kod yapısı. / Clean and organized code structure.
- 📱 **Tam Duyarlı / Fully Responsive:** Farklı ekran boyutlarına kusursuz uyum. / Seamless adaptation to different screen sizes.
- ✨ **Dinamik Yapı / Dynamic Structure:** JavaScript ile desteklenen akıcı kullanıcı deneyimi. / Smooth user experience powered by JavaScript.

## 🛠️ Kullanılan Teknolojiler / Tech Stack
* **HTML5:** Semantik web iskeleti / Semantic web skeleton
* **CSS3:** Stil ve esnek tasarım yönetimi / Styling and flexible design management
* **JavaScript:** Sayfa etkileşimleri / Page interactions
